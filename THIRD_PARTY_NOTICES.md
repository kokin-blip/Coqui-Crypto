# Third-party notices

## React Bits interaction patterns

Coqui includes small, substantially rewritten interaction patterns inspired by
React Bits. The adaptations use Coqui's own CSS timing and accessibility rules;
they do not include GSAP, OGL, continuous animation, ambient backgrounds, or
hidden-on-load content.
