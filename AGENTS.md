# Repository working instructions

## Linear progress updates

At the end of every completed task in this repository, update the corresponding
issue in the Coqui-Crypto Linear project using the Linear plugin. This is a
standing instruction from kokin; no additional confirmation is needed for these
issue updates or completion comments.

- Reuse the matching issue. Create one only if the completed work has no matching
  issue, and place it in the appropriate existing project milestone.
- Record what changed, the verification performed, and relevant commit, PR or
  evidence links. Distinguish local implementation from merged or released work.
- Set the status to reflect the issue's acceptance criteria. Use In Review when
  implementation is complete but review remains; use Done only when the issue's
  required work and checks are complete. Do not close unmet release, owner or
  elapsed-evidence gates.
- Leave a concise completion/progress comment ending with **Completed by: kokin**.
  This credits kokin without changing existing assignees or claiming review or
  release approval.
- Update affected milestone/project progress when the completed work changes the
  roadmap. Preserve dependencies and historical evidence.
- If Linear is unavailable, report the pending update in the final response;
  never claim it was synchronized.
